# Core Concepts

The HWaaS is a hardware-in-the-loop (HIL) testing platform designed for CI/CD testing, debugging, and development.

Users can create (contexts)[#contexts], which are a collection of bare metal resources with a specific lifetime.

## Motivation

The HWaaS was created to meet the following needs:

- Shared access to hardware amongst a team
- Manage a fleet of devices booted from a USB-MASS device
- Manage networking between machines
- Send and receive serial output
